# สิ่งที่รอตัดสินใจ และงานที่ค้างอยู่

> **กฎของไฟล์นี้: เขียนเป็นภาษาไทยเท่านั้น** (ชื่อไฟล์ ชื่อ tag และคำเทคนิคเขียนภาษาอังกฤษได้) ทุกครั้งที่ AI หรือระบบอัตโนมัติเจอเรื่องที่ต้องให้ผู้ใช้ตัดสินใจ หรือทำงานค้างไว้ ให้มาเพิ่มที่นี่ อย่าถามกลางคันหรือเดาเอง เมื่อผู้ใช้ตอบแล้วให้ย้ายรายการไปหมวด "ตัดสินใจแล้ว" ท้ายไฟล์ แล้วปลด BLOCKED ใน [auto-tasks.md](auto-tasks.md)

ช่องทางตอบ: หน้า Artifact "หน้าตอบคำถามโครงการ DM" (https://claude.ai/artifact/Xku6c1xrbQzuzmgcJFjuxx) เลือกคำตอบในหน้านั้นแล้วบอกว่า "อ่านคำตอบจากหน้าตอบคำถาม" หรือเติมช่อง **คำตอบ** ในไฟล์นี้แล้วบอกว่า "ทำตาม pending.md" ข้อที่ว่างไว้ = ยังไม่ปลด

## 1. รอผู้ใช้ตัดสินใจ
