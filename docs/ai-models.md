# รุ่น AI (Gemini)

สำรวจเมื่อ 2026-10-09 ด้วย `models.list` ของคีย์โปรเจกต์ (เฉพาะรุ่นที่รองรับ `generateContent`) แล้วลองเรียกจริงรุ่นละ 3 ครั้งด้วย prompt เล่าเรื่องรอบต่อสู้ (ภาษาไทย 2–3 ย่อหน้า) หน่วยวินาที ไม่ได้ใช้ streaming

## รุ่นที่เลือก: `gemini-3.5-flash` (`GEMINI_MODELS.narrationPremium`)

เร็วและนิ่งที่สุดในกลุ่มที่ไม่ใช่ lite: เวลา 9.7 / 10.5 / 10.1 วินาที (มัธยฐาน 10.1) ไม่มี error ต่ำกว่าเกณฑ์ 20 วินาที

|---|---|---|---|

รุ่น pro ที่มีในรายการ (`gemini-2.5-pro`, `gemini-3.1-pro-preview`, `gemini-pro-latest`) ไม่ได้วัดเพิ่ม เพราะ 3.1 pro ติด 429 บนคีย์นี้

## หมายเหตุ

- รุ่น 3.6–3.8 ตอบ 503 บ่อย (ช่วงที่วัด) ค่าเหล่านี้เปลี่ยนได้ ควรวัดซ้ำก่อนเปลี่ยนรุ่น
- รุ่น lite เดิม (`primary` = `gemini-3.5-flash-lite`, `fallback` = `gemini-3.1-flash-lite`) ไม่เปลี่ยน
- งานต่อไป: R2–R4 ใช้ `narrationPremium` เฉพาะรอบเล่าเรื่อง/บทส่งท้าย/ภาคต่อ เมื่อห้องตั้ง "ดี" และถอยกลับ lite เมื่อช้าหรือ error
