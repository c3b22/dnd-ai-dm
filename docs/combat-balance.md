# สมดุล combat (I5)

ผลจำลอง 1,000 ครั้งต่อช่องตาราง จาก `simulateFight` / `simulateMany` ใน `src/lib/combat/simulate.ts` ซึ่งเรียกโมดูลจริงของ combat (`armorClass`, `runAttacks`, `runEnemyAttacks`, `applyEnemyAttackOutcomes`, trait ของศัตรู I4, `applyAbilityActions` ของ class, `advanceEncounter`) ไม่ได้คัดลอกสูตรมาเขียนใหม่ **ไม่ได้แก้ค่าคงที่ใดๆ** ข้อเสนอจูนอยู่ในหัวข้อ "ข้อเสนอจูน" ด้านล่าง

สร้างตารางใหม่ได้ด้วย (ไม่รันตอน `npm test` ปกติ, seed คงที่ ผลซ้ำได้):

```
SIM_REPORT=out.md npx vitest run src/lib/combat/simulate.report.test.ts
```

## เป้าหมาย

- การต่อสู้ปกติจบใน 3-5 รอบ
- บอสที่เลเวลเหมาะสมชนะ 70-85%

## สมมติฐานของการจำลอง

- ปาร์ตี้ 4 คน คนละ class (นักรบ, นักธนู, นักบวช, โจร) เลเวล 1 / 3 / 5 / 8 · XP ตามตารางเลเวล · HP = 20 + 5 x (เลเวล-1) · ค่า ability เริ่มต้นของ class + แต้มเพิ่มค่าที่เลเวล 4 และ 8 ลง ability หลัก (+2 ต่อครั้ง) · ไม่มีไอเท็มวิเศษ
- สองโปรไฟล์เกราะ: "ไม่มีเกราะ" (ชุดเริ่มต้นจริงของเกม ไม่มีเกราะ) และ "เกราะประจำ class" (นักรบ เกราะเหล็ก, นักบวช เกราะโซ่, นักธนู/โจร เกราะหนัง)
- ผู้เล่นทุกคนโจมตีศัตรูที่เหลือ pip น้อยที่สุด (เล็งโดยไม่มี advantage) ดาเมจ = ลูกเต๋าอาวุธ + โบนัสเลเวล ยกเว้นนักรบ/นักบวชที่ใช้ท่าประจำ class ในรอบนั้น (ยืนบังเพื่อนที่ HP น้อยสุด / อวยพรรักษาเพื่อนที่ขาด HP >= 5) ซึ่งใช้แทนการโจมตี นักธนู/โจรใช้ท่าทุกครั้งที่พร้อมและยังโจมตีด้วยดาเมจใหม่ · คูลดาวน์เดินตามจริง (`tickCooldowns`)
- ผู้เล่นลงมือก่อน ศัตรูที่ยังเหลือหลังรอบนั้นแต่ละตัวโจมตีผู้เล่นที่ยังไม่ล้มแบบสุ่ม 1 คน (บอส `boss_signature` โจมตี 2 คนทุกรอบที่ 3) ศัตรูที่ถูกกำจัดในรอบนั้นไม่โต้กลับ
- ไม่จำลอง potion, การหนี, death save, การฟื้น: คนที่ HP เป็น 0 ล้มค้างจนจบการต่อสู้ ("คนล้ม" = จำนวนคนที่ล้มตอนจบ) ไม่ใช่ตาย
- ต่อสู้ครั้งเดียวต่อรอบจำลอง เริ่มด้วย HP เต็มและคูลดาวน์ 0 ถ้ายังไม่จบใน 30 รอบนับเป็นแพ้
- "HP ปาร์ตี้ที่เหลือ" = ผลรวม HP ปัจจุบัน / ผลรวม HP สูงสุด ตอนจบ เฉลี่ยทุกครั้ง
- ชุดศัตรูมาตรฐาน: minion x4, normal x2, strong x1 + normal x1, boss x1 และชุด trait: normal x2 (pack, brute), boss x1 (armored, boss_signature)

## สรุปผลปัจจุบัน

- การต่อสู้ **ง่ายเกินไปมาก**: ทุกชุดที่ไม่มี trait ชนะ 100% ที่ทุกเลเวล แม้บอสเลเวล 1 ชนะ 100% และเสียแค่ราว 10-14% ของ HP ปาร์ตี้ (เป้า 70-85%)
- การต่อสู้ปกติจบเร็วเกินไป: normal x2 ใช้ 1.2-1.7 รอบ, minion x4 / strong + normal ใช้ 2.2-2.9 รอบ (เป้า 3-5) บอสเปล่าใช้ 2.0-3.0 รอบ
- สาเหตุ: ปาร์ตี้ 4 คนโจมตีพร้อมกัน (ราว 3-4 pip ต่อรอบ) แต่ pip ของศัตรูน้อย (2 / 3 / 5 สำหรับ normal / strong / boss) และศัตรูตัวเดียวโจมตีได้ครั้งเดียวต่อรอบ ดาเมจ (เช่นบอสเฉลี่ย 9) เทียบกับ HP ปาร์ตี้ 80+ แทบไม่มีผล เกราะเปลี่ยนผลเล็กน้อยเพราะ AC ผู้เล่น 10-16 เทียบโบนัสศัตรู +3..+7
- เฉพาะบอสที่มีทั้ง `armored` + `boss_signature` ที่เลเวล 1 ถึงจะเริ่มมีความเสี่ยง (ชนะ 98.5% / ล้มเฉลี่ย 0.28 คน)

## ข้อเสนอจูน

**ยังไม่ได้แก้ค่าในโค้ด** ลองจูนชั่วคราวในเครื่อง (แล้วย้อนกลับ) ได้ชุดนี้ซึ่งทำให้เข้าเป้าที่สุดโดยไม่เปลี่ยนโครงสร้างอื่น:

| ค่า | ปัจจุบัน | เสนอ | ไฟล์ |
|---|---|---|---|
| pip ต่อ tier (minion / normal / strong / boss) | 1 / 2 / 3 / 5 | 2 / 4 / 6 / 10 | `TIER_PIPS` ใน `src/lib/combat/encounter.ts` (ควรย้ายเข้า `constants.ts`; `normalizeEncounter` ตรวจ `maxPip` กับตารางนี้ และ UI อ่านจาก `maxPip` อยู่แล้ว) |
| โบนัสโจมตีศัตรู (minion / normal / strong / boss) | +3 / +4 / +5 / +7 | +3 / +5 / +6 / +9 | `ENEMY_ATTACK_BONUS` |
| ดาเมจ normal | 1d6+1 | 1d8+2 | `ENEMY_DAMAGE_DICE` |
| ดาเมจ strong | 2d4+2 | 2d6+3 | `ENEMY_DAMAGE_DICE` |
| ดาเมจ boss | 2d6+2 | 3d6+4 | `ENEMY_DAMAGE_DICE` |
| ดาเมจ minion, AC ศัตรู, ค่าคงที่ pip ของท่าผู้เล่น | คงเดิม | คงเดิม | - |

ผลที่ได้ (ตารางด้านล่าง): normal x2 ใช้ 2.2-3.1 รอบ, strong + normal 2.9-4.5 รอบ, minion x4 2.4-3.4 รอบ, บอสเปล่าเลเวล 1 ชนะ 89% เมื่อมีเกราะ (79.9% เมื่อไม่มีเกราะ, ใช้ 5.7 รอบ) เลเวล 3 ชนะ 99%, บอส `armored` + `boss_signature` เลเวล 1 ชนะ 49% / เลเวล 3 ชนะ 84% / เลเวล 5 ชนะ 99.8%

ข้อสังเกตเพิ่มเติม:
- ปาร์ตี้เลเวลสูงยังชนะง่ายแม้ใช้ตัวเลขชุดใหม่ (ศัตรูไม่โตตามเลเวล) การปรับความยากตามเลเวลต้องให้ AI เลือก tier / trait ที่หนักขึ้นตามเลเวลปาร์ตี้ (เช่น บอสเลเวล 5 ขึ้นไปควรมี trait 2 ตัว) แนะนำเพิ่มบรรทัดนี้ใน prompt ของ combat ถ้ายอมรับ
- บอสเปล่าเลเวล 1 ที่ 89% (มีเกราะ) สูงกว่าเป้า 70-85% เล็กน้อย แต่บอสที่มี trait อยู่ในช่วงต่ำกว่าเป้า (49% ที่ Lv1) ค่าเฉลี่ยของบอสทั้งสองแบบอยู่ราวเป้า ถ้าอยากให้บอสเปล่าเข้าเป้าเดี่ยวๆ ให้ขยับโบนัสโจมตีบอสเป็น +10
- ผู้เล่นเลเวล 1 (HP 20) อาจถูกบอสคริติคอลตาย: 6d6+4 เฉลี่ย 25 ในครั้งเดียว ควรรอผู้ใช้ตัดสินใจว่ารับได้ไหม (death save ยังช่วยได้)
- ข้อจำกัดของการจำลอง: ไม่มี potion/การหนี/death save/ไอเท็มวิเศษ และศัตรูเลือกเป้าสุ่ม ผลจริงอาจต่างเล็กน้อย
