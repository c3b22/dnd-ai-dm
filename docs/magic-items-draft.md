# ร่างรายการไอเท็มวิเศษ (F5a)

สถานะ: **ร่างให้ผู้ใช้ตรวจ ยังไม่ได้ใส่ในโค้ด** เมื่อตรวจแล้วบอกว่าอนุมัติหรือขอแก้ งาน F5b จะนำไปใส่ใน `src/lib/inventory/catalog.ts`, `src/lib/character/constants.ts`, `src/lib/economy/prices.ts` ตามลำดับ ตัวเลขทั้งหมดเป็นค่าเริ่มต้นที่ผมเสนอ ยังไม่เคยลองเล่นจริง

## ระบบปัจจุบันที่ร่างนี้อิงอยู่ (อ่านจากโค้ด)

- ไอเท็มมี 3 ชนิด: อาวุธ (ลูกเต๋าดาเมจ), เกราะ (ลดดาเมจที่โดน `reduction`), ของใช้ฟื้น HP (`heal`) สวมใส่ได้ช่องละ 1 ชิ้น (อาวุธ 1, เกราะ 1) กระเป๋าจุได้น้ำหนักรวม 10
- ดาเมจศัตรูโจมตีผู้เล่นคงที่ minion 2 / normal 4 / strong 6 / boss 8 ลบ `reduction` ของเกราะ ต่ำสุด 1 (`src/lib/combat/constants.ts`) เกราะธรรมดาสูงสุดตอนนี้คือ 3
- อาวุธธรรมดาทอย d2 ถึง d8 (มือเปล่า d2, กริช/ไม้เท้า d4, ธนู d6, ดาบสั้น d8) ทั้ง 4 class ถืออาวุธต่างกันคนละแบบ จึงให้อาวุธวิเศษครบทั้ง 4 แบบ
- ไอเท็มที่ AI แจกผ่าน `[[give: ชื่อ | id]]` ต้องมี id ในรายการ catalog ส่วนในร้านค้าต้องมีราคาในตาราง `PRICES` ทุก id
- ความเสียหายหนัก (หัก 2 pip ศัตรู) คิดจากดาเมจ ≥ 75% ของค่าสูงสุดของอาวุธ (`src/lib/combat/attack.ts`)

## รายการ 10 ชิ้น

ความหายาก 3 ระดับ: **ไม่ธรรมดา** (+1) · **หายาก** (+2 หรือผลพิเศษ) · **ตำนาน** (เปลี่ยนเกม) คอลัมน์ "แก้โค้ด" บอกว่าชิ้นนั้นใส่เพิ่มแค่ข้อมูล หรือต้องมีกลไกใหม่

|---|---|---|---|---|---|---|---|---|

| M2 | `shortbow_plus1` | ธนูขนนกฟ้า | ธนูสั้น ทอย 1d6+1 | 2 | ไม่ธรรมดา | เหมือน M1 | 90 / 45 | ข้อมูลล้วน |

เหตุผลของตัวเลข
- อาวุธ +1 เพิ่มดาเมจเฉลี่ยราว 1 แต้ม (ดาบสั้นเฉลี่ย 4.5 → 5.5) และ +2 ให้ไม้เท้า/กริชที่เต๋าเล็กใกล้เคียงอาวุธ d6–d8 ไม่เกินอาวุธธรรมดาชั้นบนมากนัก
- เกราะ M5 เท่ากับเกราะโซ่แต่เบากว่า, M6 เท่ากับเกราะเหล็กแต่เบากว่า เป็นของที่ "ดีกว่าแต่ไม่พัง" เพราะลดดาเมจศัตรู 4 ระดับ (2/4/6/8) ได้ไม่มาก ส่วน M7 ที่ลด 4 จะทำให้ minion ทำดาเมจได้แค่ 1 จึงให้เป็นระดับตำนาน
- ราคาซื้ออาวุธวิเศษ ≈ 3× ราคาอาวุธธรรมดา (ธรรมดา 20–30) เกราะ ≈ 1.5–2× เกราะที่เทียบเท่า ขายคืนครึ่งหนึ่งตามกติกาเดิม (`sellPrice` ปัดลง)
- ทองที่ผู้เล่นได้จาก tag `[[gold]]` มี 3 ระดับ (เฉลี่ยราว 7 / 15.5 / 31) ราคา 90–160 จึงต้องสะสมหลายรอบ ไม่ซื้อได้ทันที

## กติกาการแจก (ใส่ใน prompt ของ AI ตอน F5b)

- **ไม่ธรรมดา:** แจกจากหีบ ของรางวัลภารกิจกลาง หรือขายในร้านพิเศษ (ร้านที่ AI เปิดด้วย `[[shop]]` เลือกรายการเอง) ไม่เกิน 1 ชิ้นต่อทีมต่อฉากใหญ่
- **หายาก:** แจกจากบอสหรือภารกิจใหญ่ ขายในร้านได้แต่เป็นของเฉพาะเจาะจงที่ AI ตั้งใจให้
- **ตำนาน:** แจกได้เฉพาะตอนจบ arc หรือบอสสุดท้าย ไม่เกิน 1 ชิ้นตลอดแคมเปญ ห้ามใส่ใน `[[shop]]` (server ควรกรองทิ้งเองไม่พึ่ง AI)
- เกินน้ำหนักกระเป๋าแล้ว `giveItem` คืนผล `full` ตามระบบเดิม AI ต้องเล่าให้ผู้เล่นตัดสินใจทิ้งของ

## สิ่งที่ F5b ต้องทำ ถ้าอนุมัติ

1. M1–M7: เพิ่ม id ใน `WEAPONS` (`src/lib/character/constants.ts`, อาวุธเท่านั้น) และ `CATALOG` (`src/lib/inventory/catalog.ts`) และ `PRICES` (`src/lib/economy/prices.ts` ซึ่งบังคับให้ทุก id มีราคา) **ต้องเพิ่มใน `WEAPONS` ด้วย** เพราะ `weaponFor` ใน `src/lib/character/constants.ts` ถ้าไม่รู้จัก id จะตกไปเป็นมือเปล่า (d2) เงียบๆ
2. M8: เพิ่มชนิดของใช้ที่ลด pip ศัตรู (ต่อกับ `src/lib/combat/encounter.ts` และการใช้ยาใน `src/lib/inventory/apply.ts`) + test
3. M9–M10: เพิ่มช่อง `accessory` (migration ถ้า DB เก็บ slot เป็น enum/check, ดู `0008_inventory.sql`), ช่องสวมใน `equipItem.ts`, ตัวบวกในการเช็ก (`src/lib/character/check.ts`/`classes.ts` `skillModifier`) + test; M10 รอระบบ death save (H1)
4. เพิ่มกติกาการแจกด้านบนใน prompt (`src/lib/inventory/prompt.ts`) และกรอง id ระดับตำนานออกจาก `[[shop]]` ฝั่ง server (`src/lib/economy/shop.ts`)
5. เพิ่มรูปไอเท็ม/ชื่อภาษาไทยในหน้ากระเป๋า (`src/components/Inventory.tsx`) ถ้ามีการแสดงความหายาก

## ข้อที่ต้องการให้ผู้ใช้ตัดสิน (คัดลอกไปที่ pending.md แล้ว)

1. จำนวนและชนิด: พอใจ 10 ชิ้นนี้ไหม จะตัดชิ้นไหนออก (เช่น ตัด M8–M10 ที่ต้องมีกลไกใหม่ออกก่อน แล้วทำเฉพาะ M1–M7 ซึ่งเพิ่มแค่ข้อมูล) หรือเพิ่มชิ้นอะไร
2. แหวนและเครื่องราง (M9, M10) ต้องการช่องสวมใหม่ `accessory` ซึ่งเป็นงานเพิ่มในระบบกระเป๋าและฐานข้อมูล ยอมให้ทำไหม หรือเปลี่ยนเป็นของที่ไม่ต้องสวม (เช่นของใช้ครั้งเดียว)
3. ไอเท็มระดับตำนานไม่ขายในร้านตามร่างนี้ ใช้ได้ไหม
4. ตัวเลขราคาและดาเมจ (หัวข้อ "เหตุผลของตัวเลข") ใช้เป็นค่าเริ่มต้นได้ไหม
