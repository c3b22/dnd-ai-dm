# Feature Backlog

- [ ] แชร์โครงเรื่อง (adventure) ให้คนอื่นนำไปเล่นได้
- [ ] ลบ campaign ที่เล่นค้างไว้และไม่อยากเล่นต่อได้
- [ ] Combat tracker: แสดงศัตรูในการต่อสู้พร้อมช่องความทน (pip) ให้ผู้เล่นเห็นว่ามีศัตรูกี่ตัว เหลือเลือดเท่าไหร่ (design คร่าวๆ ตกลงแล้ว ยังไม่ได้ทำ UI design / spec)
  - เก็บเป็น `campaigns.current_encounter jsonb` ตาม pattern ของ `current_shop` (sync ผ่าน realtime, server เขียนตอนจบ round)
  - Tag ใหม่: `[[enemy: ชื่อ | minion/normal/strong/boss]]`, `[[enemy_hurt: ชื่อ | light/medium/heavy]]`, `[[enemy_flee: ชื่อ]]`, `[[combat_end]]`
  - Pip: minion 1, normal 2, strong 3, boss 5; light/medium หัก 1, heavy หัก 2 (server บังคับ บอสตายในทีเดียวไม่ได้)
  - pip เหลือ 0 = ล้ม (แสดงขีดฆ่าจนจบการต่อสู้); จบอัตโนมัติเมื่อล้ม/หนีหมด, `[[combat_end]]` หรือเปลี่ยนฉาก
  - ชื่อซ้ำเติมเลขอัตโนมัติ (`หมาป่า 2`), ชื่อไม่ตรงให้เมิน, จำกัด 8 ตัว
  - ไม่มีรางวัลอัตโนมัติ: AI ให้ XP/ทองผ่าน tag เดิม
  - ยังเหลือ: ออกแบบ UI panel, เขียน spec, เขียน plan
  - ต่อยอดภายหลัง: zone-based positioning → grid map เต็มรูปแบบ (ใหญ่มาก ต้องมี enemy entity ก่อน)

## ข้อเสนอให้เล่นสนุกใกล้ D&D จริงขึ้น (วิเคราะห์จากโค้ด 2026-10-06, ยังไม่ได้ทดลองเล่น)

ลำดับที่แนะนำให้ทำก่อน: 1) ทอยแบบมี DC/skill → 2) ปรับ combat tracker ให้ damage ผูกกับ pip → 3) ถาม DM/แชททีมไม่กินรอบ

- [ ] **ทอยเต๋าให้มีความหมาย** — ตอนนี้ server ทอย d20 ให้ทุก action ล่วงหน้าโดยไม่รู้ว่าเป็น action อะไร (`src/lib/round/processRound.ts`)
  - ให้ AI สั่งทอยเอง พร้อมบอก skill + DC (เช่น "ทอย Stealth DC 15") ให้ทุกคนลุ้นตาม
  - เพิ่มค่าความสามารถแบบง่าย (อย่างน้อย 3–4 ค่า) + skill/proficiency ให้แต่ละ class ต่างกันจริง
  - advantage/disadvantage เป็นรางวัลให้แผนที่ดี
- [ ] **Combat ให้จับต้องได้** (เอาไปรวมตอนเขียน spec ของ combat tracker ด้านบน)
  - ให้ server แปลง damage ที่ผู้เล่นทอยเป็น pip เอง แทนให้ AI เลือก light/medium/heavy (ไม่งั้นทอยดี/แย่รู้สึกเท่ากัน)
  - ศัตรูทอยโจมตีใส่ผู้เล่น เทียบกับ AC/เกราะ แทนให้ AI ตัดสิน `hurt` เอง
  - ภายหลัง: ตำแหน่ง/ระยะ (zone) ให้ธนูกับดาบต่างกันเชิงยุทธวิธี
- [ ] **จังหวะการเล่นยืดหยุ่นขึ้น** — ตอนนี้ 1 รอบ = 1 action + timer
  - ช่อง "ถาม DM ฟรี" ตอบสั้นๆ ไม่จบรอบ ไม่ทอยเต๋า (ถามรายละเอียดฉาก/คุยกับ NPC)
  - แชททีม (OOC) ที่ไม่ส่งไป AI ไว้วางแผนกัน
- [ ] **ตัวตนและการเติบโตของตัวละคร**
  - backstory / บุคลิก / เป้าหมายส่วนตัว ส่งเข้า prompt ให้ DM ผูกเนื้อเรื่องกับตัวละคร
  - เลเวลอัปมีทางเลือก (ท่าใหม่/feat) ไม่ใช่แค่ +HP +damage (`src/lib/character/leveling.ts`)
  - ไอเท็มวิเศษที่มีผลเชิงกลไกจริง ให้ loot น่าตื่นเต้น
- [ ] **ความทรงจำของโลกเกม** — summary ถูกย่อทุก 8000 ตัวอักษร (`src/lib/round/assemblePrompt.ts`) รายละเอียดหายได้
  - เก็บข้อเท็จจริงแบบมีโครงสร้าง: NPC + ทัศนคติต่อทีม, ภารกิจค้าง, เบาะแส
  - แสดง quest log / สมุดบันทึกให้ผู้เล่นเห็น
- [ ] **เพิ่มเดิมพัน** — ตอนนี้ตายจริงไม่ได้ (ชุบได้เสมอ, ทีมแพ้แค่โดน story consequence)
  - death save 3 ครั้งแบบทอยให้ทุกคนเห็น
  - ตัวเลือกโต๊ะ: โหมดตายจริง (เช่นผูกกับ difficulty hard)
